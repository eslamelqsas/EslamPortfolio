About The Project

JobFinder is a job search web application developed as a practical ASP.NET Core MVC project.

The platform allows users to create accounts, log in securely, browse available jobs, apply for jobs and track their submitted applications.

Main Features

User Registration

Users can create a new account using their name, email and password.

Secure Login

Users can log in and maintain their session while using the platform.

Job Search

Users can browse jobs by title, category and other job information.

Apply For Jobs

Registered users can submit applications with their personal information and cover letter.

CV Upload

Applicants can upload their CV in PDF, DOC or DOCX format.

Application Tracking

Users can view their previous applications and track submitted job applications.
